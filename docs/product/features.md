# GlobeTalk Web App Features

> Project 9: Virtual Pen Pals — core capabilities and current scope

This document outlines the key features and functionalities of the **GlobeTalk** web application, aligned with the Project 9 brief. It is intended for product, design, and engineering teams to share a common understanding of what exists now and what is planned next.

---

## Project‑Specific Features

* **Random Matchmaking**
  Match with a new pen pal from a random country using your **language** and/or **time‑zone** preferences to ensure basic overlap.

* **Asynchronous Messaging (Delayed Delivery)**
  Send and receive **text‑only** letters that are delivered after a **simulated delay** (e.g., **12 hours**) to mimic postal mail pacing.

* **Cultural Profiles**
  Write a short, anonymous intro and view neutral, anonymous facts (e.g., **age range**, **hobbies**, **region**) about your pen pal.

* **Safety & Moderation**
  Keep all chats **anonymous** (no names/emails/media). Users can **flag** inappropriate content and **block** others. PII and links are discouraged or blocked by policy.

---

## Hidden Features (Not Yet Implemented)

* **IP‑based Ban Tracking**
  Track and ban users by IP address to reduce re‑registration by banned users.

* **PDF Export**
  Export message threads as a PDF for local storage or printing.
