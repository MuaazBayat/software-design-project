# Environment Variables

This project requires environment variables to run correctly, as they contain sensitive information (e.g., API keys and credentials).

* For security reasons, these variables are **not** included in the repository.
* Please contact the project owner to obtain the necessary `.env` file and setup instructions.

## Local Setup (Quick Start)

1. **Request** the `.env` file from the project owner.
2. **Place** the file in the appropriate location (usually the project root, unless otherwise specified).
3. **Restart** your dev server after adding or changing environment variables.

> **Note:** Do **not** commit `.env` files. Ensure your `.gitignore` excludes them.
