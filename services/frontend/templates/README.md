Drop your SVG templates here to keep them alongside the compose-letter UI.

How to use
- Place small, tileable SVGs or single large SVGs in this folder.
- Reference them from the UI as `/compose-letter/templates/<filename>.svg`.

Naming suggestions
- Use lowercase, hyphen-separated names: `rustic-paper.svg` or `lined-paper.svg`.
- If you want preview thumbnails, add `preview-` prefixed files (e.g. `preview-rustic-paper.svg`).
